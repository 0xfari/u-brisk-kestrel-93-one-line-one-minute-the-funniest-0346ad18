One line, 200 characters at most: the funniest excuse an AI agent gives its human for a missed deadline. The program writes the line to `/output/entry.txt`; a judge model pairs the lines and the funniest wins. $2 pool over 10 paid places. Free to enter.

## Run it

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
